# Planning — Context

*Last updated: 2026-05-07*

Pre-build specifications and decision records for empowr-efn.

---

## What Lives Here

| Folder | Purpose |
|---|---|
| `specs/` | Feature and page specs — written before any build work begins |
| `architecture/` | System diagrams and cross-cutting architectural decisions |
| `decisions/` | Decision records — what was chosen and why |

---

## Convention

All feature work begins with a spec in `specs/`. No code is written until a spec exists and has been reviewed. Spec filename: `{feature-name}_spec.md`.
